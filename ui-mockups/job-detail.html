Nguồn: TopCV Cũng thấy trên ITviec · đã gộp trùng

Mô tả công việc

  • Phát triển và bảo trì hệ thống backend Java / Spring Boot.
  • Thiết kế API, tối ưu truy vấn SQL và tích hợp microservices.
  • Tham gia code review, viết unit test và phối hợp với team frontend/QA.
  • Theo dõi log, xử lý sự cố production theo sprint 2 tuần.

Yêu cầu

  • 1-3 năm kinh nghiệm Java, nắm vững OOP và Spring ecosystem.
  • Có kinh nghiệm SQL, Redis hoặc Kafka là lợi thế.
  • Tiếng Anh đọc tài liệu kỹ thuật.

Quyền lợi

  • Lương 25-35 triệu, 13 tháng lương, review 2 lần/năm.
  • Bảo hiểm đầy đủ, hybrid 2 ngày/tuần.
  • Đào tạo nội bộ, hỗ trợ chứng chỉ AWS/Java.
